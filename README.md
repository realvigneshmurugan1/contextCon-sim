# Anti-Gravity: The Market Physics Engine 🛰️

Anti-Gravity is an autonomous market intelligence platform built during the 2026 Bengaluru AI Hackathon. It treats the Bengaluru tech ecosystem as a complex physical system, using real-time firmographics to detect Structural Fractures and Institutional Memory Leakage before they manifest in public markets.Built with Node.js, Google Antigravity, and the full Crustdata API Suite.

# 🚀 The Core Philosophy: "Market Physics"

Most firmographics are static "history books." Anti-Gravity is a real-time Telemetry System.We apply Chaos Engineering principles (inspired by Netflix's Chaos Monkey) to human capital. By analyzing the "Gravity" of elite talent clusters, we can predict when a company's technical moat is about to enter Freefall (Entropy).

# 🛠️ Tech Stack
   **Engine**: Node.js (TypeScript) - Event-driven, non-blocking I/O for high-throughput market telemetry. \n
   **Orchestration**: Google Antigravity (Multi-agent workflow).Intelligence: Gemini 1.5 Pro (Surgical Diligence Briefing).
   **Visuals**: Streamlit / Pydeck (3D Geospatial Mapping of Bengaluru Tech Hubs).
   **Data**: 
     * Crustdata Watcher API: Live talent exodus detection.
     * Crustdata People API: Knowledge Hub identification & Pedigree mapping.
     * Crustdata Technographics API: Infrastructure health vs. Talent flux.
     * Crustdata Company API: Funding runway & growth velocity.
